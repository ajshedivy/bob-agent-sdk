# Release notes

Write release notes in this format, and in no other:

1. A title line: `Release <version>: <codename>`. Read the codename for the version from `codenames.txt` in this skill folder.
2. A section `What changed` with at most three bullets. Each bullet starts with a verb in the past tense.
3. A last line: `Questions: #release-help`.

Do not add any other sections.
